# Backtesting Engine

This module will test the trading strategy using historical XAUUSD data.

## Testing Process

Historical Data
↓
Strategy
↓
Signal Generation
↓
Entry
↓
Stop Loss
↓
Take Profit
↓
Trade Result
↓
Performance Analysis

## Metrics

- Win Rate
- Profit Factor
- Expectancy
- Maximum Drawdown
- Sharpe Ratio
- Sortino Ratio
- Average R
- Number of Trades
- Maximum Adverse Excursion
- Maximum Favorable Excursion

## Testing Methods

- Historical Backtest
- Out-of-Sample Test
- Walk-Forward Test
- Monte Carlo Analysis

## Safety

No live trading is allowed from the backtesting engine.
