# AI Agent Layer

This module will coordinate AI-powered research and decision support.

## Agents

### 1. Macro Agent
Monitors:
- Economic news
- CPI
- NFP
- FOMC
- Interest rates
- USD strength

### 2. Technical Agent
Analyzes:
- 4H trend
- 1H trend
- 15M structure
- Liquidity
- BOS
- CHOCH
- Volatility

### 3. Portfolio Agent
Monitors:
- Account equity
- Open positions
- Current risk
- Daily loss
- Drawdown

### 4. Master Agent
Combines information from all agents and produces a structured trade plan.

## Safety

AI agents provide analysis only.

No agent can bypass the Risk Guardian.
