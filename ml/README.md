# Machine Learning Engine

This module will develop machine learning models for XAUUSD market research.

## Initial Model

- XGBoost

## Future Models

- Random Forest
- LightGBM
- PPO

## Features

- RSI
- ATR
- EMA
- ADX
- Bollinger Bands
- Higher Timeframe Bias
- Liquidity Sweep
- BOS
- CHOCH
- Volatility
- Trading Session

## Prediction

The model will estimate:

- BUY probability
- HOLD probability
- SELL probability

## Safety

Machine learning predictions will not directly execute trades.

All signals must pass through the Risk Guardian.
